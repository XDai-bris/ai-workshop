# Notes for AI agents in this project

- All data are simulated. The researcher directs and reviews the work; keep it easy to check.
- Run R as `conda run -n ieu-ai-workshop Rscript <file>`. Base R only: do not install or load add-on packages.
- Analysis code goes in `analysis/`, outputs in `results/`. Use relative paths. Stay inside this folder.
- Quote numbers from the files in `results/`, not from memory.
