How this case was made

Provenancedata, models, what was planted, what was not

Data. Simulated summary statistics for 100 BMI instruments, generated in base R. They contain the hazards real files have: effect alleles reported either way round, a strand mix-up, palindromic SNPs, a missing-value code (-9), instruments absent from the outcome GWAS, and an exposure reported in SD units. The true effect used in the simulation is 0.25 mmHg per kg/m². The correct analysis gives IVW 0.21 (95% CI 0.15 to 0.26).

Agents. Claude Sonnet 5.5 in Claude Code, run headless. Every prompt went to a fresh session with no memory or personal settings, sandboxed to the project folder, with base R only. Runs were recorded on 24 November 2026. The Stage 4 milestone prompt was also run twice by hand in the Codex desktop app (OpenAI, gpt-6.2-astra). The first run was in a chat that already had workshop context, so we reran it in a fresh chat. Both found E1; the page summarises the fresh run. Both logs show the reviewer opened only files inside the project folder.

What we changed by hand. One line in the harmonisation step (E2), before the draft was run. Nothing else. E1, the unit error, was the agent’s own: two independent builds from the same prompt both divided by 4.8.

Pre-registration. The ten review runs in Stage 2 were scored against criteria written before any of them ran, and the results are reported as they came out. In an earlier batch of ten, the sandbox blocked some commands, so reviewers could not always run code. That batch showed the same pattern: every reviewer found E2, and 1 of 10 found E1.

Things we saw while building the case. In our first version the project folder documented a dataset with a known answer. In two of the three drafting runs, the agent ran that check without being asked: once it flagged the failure, and once it found and fixed the cause. In the third, it spotted the planted line by reading the code. That is why the version shown here has no known answer in the project. It is also the evidence behind Stage 6: a check that is written down gets used.

Case files. The download contains the plan, the data, the draft, the fixed project, every prompt, and every recorded reply. A full archive, with transcripts and the simulation truth, is kept with the workshop materials.
