Review: a vague question or a specified one

5–20 min

A simple error is found whatever you ask. A deep error is found only occasionally, however well you ask. What a specified review gives you is an evidence trail, and the deep error is in that trail for you to see.

1 · A simple error: found whatever you ask

E2 leaves a visible trace. In the harmonisation log, the allele frequencies contradict the sign the script used. Every reviewer read the log, saw the contradiction and fixed the line in a scratch copy. We expected the vague prompt to miss it. It did not.

2 · A deep error: found once in ten

E1 is the agent’s own mistake, and it is consistent everywhere: in the code, the log and the report. A reviewer that is the same model, reading the same dictionary, makes the same reading. Having fixed E2, the reviewers reported a “corrected” IVW of 4.77, still 23 times too large, and took the agreement between methods as confirmation:

Coherence is not correctness. Nor could Q have warned anyone: it does not change when every exposure effect is rescaled, so it cannot detect a unit error at all (Stage 4).

3 · What the specified prompt bought: an evidence trail

The specified prompt did not make the reviewer right more often. It made the reviewer show its working, and the deep error sits in that working, in plain sight. Each card below pairs a reviewer’s claim with the line of its own code behind it:

Specified · run 1plan check, units row · and its simulation

:120-121 divide BETA and SE by 4.8 | Matches the dictionary. SD to kg/m² means dividing by 4.8, and the outcome is already in mmHg.

review/make_sim.R, line 19:
byX <- THETA * bxX / 4.8 + rnorm(n, 0, .004)

Specified · run 4plan check, units row · and its simulation

Matches the dictionary. BETA is per SD and 1 SD = 4.8 kg/m², so dividing gives per kg/m². The simulation recovers the truth to 0.5 SE, which confirms the units.

review/simulate.R, line 60:
by_V <- TRUE_EFFECT * g / SD_BMI + rnorm(1, 0, SE_Y)

A researcher who knows that a SNP effect in SD units must be multiplied by the SD to give kg/m² can catch E1 from either card in seconds: the reviewer’s known answer was built with the same division as the code, so of course it agreed. The vague reviews offer nothing to follow up, only one line saying “the unit conversion is right”.

Once, the agent followed the trail itself. Run 3 built its simulation from the data dictionary, not from the script’s formula, so its known answer could disagree with the code:

Specified review · run 3excerpt · the only run that found E1

Units (analysis/mr_analysis.R:120-121). The code does BETA / SD_BMI_KGM2. The dictionary says BETA is per SD with 1 SD = 4.8 kg/m², so the conversion to kg/m² should multiply by 4.8. Dividing makes the exposure effect 23.04 times too small and every estimate 23.04 times too large (4.8² = 23.04).
