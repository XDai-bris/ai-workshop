The agent writes the analysis

0–5 min

An agent will always return an answer that is complete, formatted and confident. Validation starts from that answer; it does not stop there.

The question is whether higher BMI raises systolic blood pressure. We answer it with two-sample MR on simulated GWAS summary statistics: 100 BMI instruments, looked up in an SBP GWAS. Before any code was written, the researcher wrote a one-page plan. It says to harmonise alleles, express effects per kg/m², use IVW as the primary method, and run MR-Egger and weighted median as sensitivity analyses.

How the data were simulatedmodel, parameters, and the files it produced

Everything is simulated in base R from one fixed seed: 100 independent BMI instruments. For SNP j, defined on its BMI-raising allele:

γⱼ = 0.01 + Exp(mean 0.012), and at least 7 × SE true SNP–BMI effect, SD of BMI per allele Γⱼ = θ × 4.8 × γⱼ + αⱼ, αⱼ ~ N(0, 0.005²) true SNP–SBP effect, mmHg per allele θ = 0.25 mmHg per kg/m² (1.2 mmHg per SD of BMI) the causal effect to recover

Allele frequencies are uniform on 0.05–0.95. Standard errors follow from sample size: 1/√(2f(1−f)N) with N = 300,000 for BMI, and 19 mmHg/√(2f(1−f)N) with N = 750,000 for SBP. Observed effects add normal noise with those SEs, and BMI estimates are redrawn until P < 5×10⁻⁸, as instrument selection would. The pleiotropy α is small and balanced (mean zero), so IVW, MR-Egger and weighted median are all valid here.
